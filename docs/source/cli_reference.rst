Controller Client
~~~~~~~~~~~~~~~~~

Command: ``python client/controller/app.py``

* ``--controller-server`` (default: ``localhost:50056``) -- Address and port of the controller
  gRPC service (default: localhost:50056)
* ``--input-audio`` (default: ``assets/sample_audio.wav``) -- Path to input audio file (default:
  assets/sample_audio.wav)
* ``--input-mp4`` (default: ``assets/sample_video_streamable.mp4``) -- Path to input video file,
  MP4. Streamable MP4 is recommended for best performance but not required; convert using the
  script provided at: scripts/misc/convert_to_streamable_mp4.sh (default:
  assets/sample_video_streamable.mp4)
* ``--ssl-mode`` (default: ``DISABLED``; choices: ``DISABLED``, ``TLS``, ``MTLS``) -- Channel
  security for the controller connection (default: DISABLED)
* ``--ssl-key`` (default: ``None``) -- Path to the client private key PEM (required for MTLS)
* ``--ssl-cert`` (default: ``None``) -- Path to the client certificate chain PEM (required for
  MTLS)
* ``--ssl-root-cert`` (default: ``None``) -- Path to the root certificate PEM used to verify the
  controller (required for TLS and MTLS)
* ``--request-id`` (default: ``None``) -- Correlation id stamped on every request message and
  echoed by the controller in its responses. Omit to generate a UUID4 per run.
* ``--chunk-size-audio-secs`` (default: ``1``) -- Chunk size for streaming audio in seconds
  (default: 1)
* ``--chunk-size-video-bytes`` (default: ``1048576``) -- Chunk size for streaming video
  (default: 1 MB)
* ``--output-mp4`` (default: ``outputs/controller_output.mp4``) -- Path to output video file,
  mp4 only. Default: outputs/controller_output.mp4
* ``--diarization-file`` (default: ``None``) -- Path to diarization file for speaker segments.
  Supports flat ASD format, ElevenLabs STT/Scribe JSON, ElevenLabs Dubbing Transcript API JSON,
  ElevenLabs Studio CSV, or Camb AI transcription JSON. Use --diarization-format to select the
  parser. Generate with: scripts/elevenlabs/diarize.py, scripts/elevenlabs/s2s_infer.py, or
  scripts/camb/diarize.py. Note: scripts/camb/s2s_infer.py also emits a 'camb'-format JSON, but
  the transcript is in the target language only.
* ``--diarization-format`` (default: ``elevenlabs-scribe``; choices: ``flat``,
  ``elevenlabs-scribe``, ``elevenlabs-dubbing-api``, ``elevenlabs-studio``, ``camb``) -- Format
  of the diarization file. 'elevenlabs-scribe' for ElevenLabs STT (Scribe) JSON;
  'elevenlabs-dubbing-api' for ElevenLabs Dubbing Transcript API JSON; 'camb' for Camb AI
  transcription/dubbing JSON (generate source-language diarization with scripts/camb/diarize.py;
  scripts/camb/s2s_infer.py emits target-language only) (default: elevenlabs-scribe). Note: the
  legacy value 'elevenlabs' was renamed to 'elevenlabs-scribe' — update any scripts/configs
  accordingly.
* ``--diarization-chunked-per-segment`` (flag) -- Emit one diarization chunk per source segment
  (e.g. per word) instead of merging consecutive same-speaker segments. Combined with
  --diarization-rows-per-chunk this streams diarization one unit at a time. By default,
  consecutive same-speaker segments are merged.
* ``--bypass-asd`` (flag) -- Bypass ASD (Active Speaker Detection) service. Auto-enabled when no
  --diarization-file is provided.
* ``--background-audio-input`` (default: ``None``) -- Path to background audio file (WAV or MP3)
  for mixing with the LipSync output (optional)
* ``--translated-audio`` (default: ``None``) -- Path to pre-translated audio file (WAV or MP3).
  When provided, S2S is bypassed and this audio is sent directly to LipSync (optional)
* ``--diarization-rows-per-chunk`` (default: ``10``) -- Number of diarization segment rows to
  send per chunk. Use -1 to send all segments in a single message (default: 10)
* ``--source-language`` (default: ``en``) -- Source language for speech-to-speech translation
  (default: en)
* ``--target-language`` (default: ``de``) -- Target language for speech-to-speech translation
  (default: de)
* ``--voice-name`` (default: ``None``) -- Voice name for TTS (optional, service will use default
  if not provided). For zero-shot TTS, the service automatically extracts voice from input
  audio.
* ``--elevenlabs-num-speakers`` (default: ``0``) -- Number of speakers for ElevenLabs dubbing. 0
  = auto-detect (default: 0)
* ``--elevenlabs-drop-background-audio`` (flag) -- Drop background audio from the final dub
  (ElevenLabs)
* ``--elevenlabs-use-profanity-filter`` (flag) -- [BETA] Censor profanities in transcripts
  (ElevenLabs)
* ``--elevenlabs-target-accent`` (default: ``None``) -- [Experimental] Accent to apply when
  selecting voices (ElevenLabs)
* ``--elevenlabs-highest-resolution`` (flag) -- Use the highest resolution available
  (ElevenLabs)
* ``--elevenlabs-watermark`` (flag) -- Apply watermark to the output (ElevenLabs)
* ``--elevenlabs-dubbing-studio`` (flag) -- Prepare dub for edits in dubbing studio (ElevenLabs)
* ``--camb-ai-optimization``/``--no-camb-ai-optimization`` (flag) -- Enable CambAI AI
  optimization (default: True)
* ``--camb-chosen-dictionaries`` (default: ``None``) -- Comma-separated CambAI dictionary IDs
  for custom terminology (e.g. '1,5,12'). Optional.
* ``--asd-input-audio-codec`` (default: ``WAV``; choices: ``WAV``, ``MP3``) -- Audio codec for
  ASD input (default: WAV)
* ``--asd-input-video-codec`` (default: ``None``; choices: ``H264``) -- Video codec for ASD
  input (optional, default: unspecified)
* ``--asd-audio-source-config`` (default: ``separate_stream``; choices: ``unspecified``,
  ``separate_stream``, ``embedded_in_video``) -- Where audio originates: separate stream or
  embedded in video (default: separate_stream)
* ``--asd-speaker-detection-threshold`` (default: ``0.5986``) -- Speaker detection confidence
  threshold in (0, 1) (default: 0.5986)
* ``--lipsync-input-audio-codec`` (default: ``None``; choices: ``WAV``, ``MP3``) -- Audio codec
  for LipSync input. Omit to auto-detect for file input.
* ``--lipsync-extend-audio`` (default: ``unspecified``; choices: ``unspecified``, ``silence``)
  -- How to handle video longer than audio (default: unspecified)
* ``--lipsync-extend-video`` (default: ``unspecified``; choices: ``unspecified``, ``forward``,
  ``reverse``) -- How to handle audio longer than video (default: unspecified)
* ``--lipsync-output-bitrate-mbps`` (default: ``20``) -- Output video bitrate in Mbps (default:
  20)
* ``--lipsync-output-idr-interval`` (default: ``8``) -- Output video IDR (keyframe) interval
  (default: 8)
* ``--lipsync-head-movement-speed`` (default: ``None``) -- Head movement speed: 0 for
  static/slow, 1 for fast (optional)
* ``--lipsync-output-audio-codec`` (default: ``None``; choices: ``WAV``, ``MP3``) -- Output
  audio codec (optional)
* ``--lipsync-is-speaker-info-provided`` (flag) -- Whether speaker bounding boxes are provided
  (from ASD). Set when ASD is enabled.
* ``--lipsync-background-audio-volume`` (default: ``1.0``) -- Background audio volume for mixing
  (0.0-1.0). 0 = muted, 1 = full volume
* ``--lipsync-background-audio-codec`` (default: ``None``; choices: ``WAV``, ``MP3``) --
  Background audio codec. Auto-detected from file extension if omitted (optional)
* ``--lipsync-lossless`` (flag) -- Enable lossless video encoding (overrides bitrate/IDR
  settings)
* ``--lipsync-custom-encoding-params`` (default: ``None``) -- Custom encoding parameters in JSON
  format (overrides bitrate/IDR settings)
